# Museum Ticket Challenge

This repository contains the supplementary material for the conference paper:

**A Progressive Transition from Scratch to Python: A Teaching Approach**

## Contents

- `museum_ticket_challenge.sb3` – Scratch implementation
- `museum_ticket_challenge.py` – Python implementation

The repository contains the complete educational project used as the case study in the paper. It demonstrates the gradual transition from Scratch to Python through the same educational scenario.
